반달은 대학 공부에 필요한 자료를 한 화면에 모으는 iPad 앱입니다. 과목별로 PDF, 노트, 필기를 정리하고, 화면을 나눠 여러 자료를 함께 봅니다.

PDF와 필기
- 강의 자료 PDF를 열어 펜, 볼펜, 형광펜으로 바로 필기합니다. Apple Pencil의 필압과 기울기를 반영합니다.
- 올가미로 필기를 선택해 옮기고, 도형과 텍스트 상자를 넣습니다.
- 원문을 선택해 형광 표시와 메모를 남기고, 페이지를 재배열하거나 삭제한 뒤 되돌릴 수 있습니다.
- 종이를 고른 빈 필기 노트와 화이트보드를 만듭니다.

노트
- 제목, 목록, 체크리스트, 표, 수식을 지원하는 Markdown 노트를 씁니다.
- PDF 페이지와 노트를 나란히 두고 연결해 정리합니다.

작업 공간
- 탭을 끌어 가로·세로로 나누고, 과목과 읽던 위치를 다음에 열 때 그대로 복원합니다.
- 학교 사이트와 수업 자료를 여는 내장 브라우저, 할 일과 일정, Apple 캘린더 연결을 제공합니다.

AI
- OpenAI, Anthropic, Google API 키를 직접 입력하면 자료를 첨부해 질문할 수 있습니다. 키는 iPad의 Keychain에만 저장됩니다.
- 제공자별로 처음 보내기 전에 동의를 받으며, 질문과 첨부 자료는 iPad에서 선택한 제공자에게 바로 전송됩니다.

저장
- 모든 자료는 iPad 안에 저장되며 계정 없이 바로 사용할 수 있습니다.
