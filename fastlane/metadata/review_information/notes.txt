반달은 로그인 없이 모든 기능을 사용할 수 있습니다. 첫 화면에서 바로 과목을 만들고 자료를 열 수 있습니다.

핵심 기능 확인 순서:
1. 왼쪽 레일의 자료실에서 "+" → 새 과목을 만듭니다.
2. 과목 안에서 "+" → 노트를 만들면 종이를 고른 PDF 필기 노트가 열립니다. 하단 팔레트에서 펜·형광펜·올가미·텍스트를 바로 사용할 수 있습니다.
3. 파일 앱에서 PDF를 가져오거나 공유 시트로 반달에 보내면 같은 팔레트로 필기할 수 있습니다.
4. "+" → 마크다운으로 노트를 만들어 표와 수식을 입력할 수 있습니다.
5. "+" → 녹음으로 강의 녹음과 기기 내 자막을 확인할 수 있습니다. 마이크 권한만 필요합니다.

로그인은 선택 사항입니다. Apple, Google, 카카오 로그인은 계정 프로필 표시와 설정 → 계정 → 계정 삭제 확인용이며, 이 버전에는 동기화·구독·결제가 없습니다.

AI 기능은 사용자가 직접 입력한 OpenAI/Anthropic/Google API 키로만 동작하므로 심사에서는 건너뛰셔도 됩니다. 키 없이도 다른 모든 기능이 동작합니다.

내장 브라우저는 WebKit 기반이며 일반 웹사이트를 열 수 있어 연령 등급을 17+로 설정했습니다.
