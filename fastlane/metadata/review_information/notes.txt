Hello,

Version 1.4.1 adds three things. There are no new in-app purchases; purchases, AI, sync and account deletion work as in 1.4.0.

1. First-run setup (4 steps, shown once on a new install; "나중에" (Later) leaves it at any step)
- Language: Korean or English, applied at once. It can be changed later in Settings > 일반 > 언어.
- School: search our school directory and pick one; the school's websites (portal, LMS, library...) then appear as shortcuts in the sidebar. No sign-in is needed.
- Invite code: an optional 6-character code from a friend ("없어요, 건너뛰기" skips it).
- Done. To see the setup again, delete and reinstall the app.

2. School setup with AI
- When a school is not in the directory, "AI로 찾기" (Find with AI) asks our server to find the school's official websites. The server runs a web search through Anthropic's API and returns only links on the school's own domain. The user reviews, edits or removes them before saving; they are labelled "AI가 찾은 정보 · 검토 전" (found by AI, not reviewed yet).
- It needs sign-in (3 searches per account per day) and sends only the school name and country the user typed. No personal data, notes or documents are sent. We pay for it; it does not use the user's AI allowance.
- Without sign-in the user can enter the school name alone ("직접 입력").

3. Friend invites
- Profile menu (bottom of the left rail) > 친구 초대, or Settings > 계정 > 친구 초대: the account's invite code with Copy and Share.
- When an invited friend signs in and creates their first course, both accounts receive AI credit worth about 100 AI questions. It is the same in-app AI credit as before: used after the monthly allowance, never expires. An account is rewarded for at most 5 friends.
- The reward is AI usage inside the app only. It has no cash value, cannot be transferred, exchanged or withdrawn, and unlocks no paid plan. No purchase is needed to invite or to be invited.
- The share text contains a link (https://bandal.io/r/CODE). With the app installed it opens the app with the code filled in; the user still taps "이 코드 적용" to apply it.

How to test
- New install: the setup appears on first launch. In step 2 type "서울" and pick 서울대학교, or type any name and choose "직접 입력".
- AI search and invites need an account: Account button in the left rail (Sign in with Apple or Google).

Unchanged from 1.4.0
- AI goes through our server (Supabase Edge Functions) to Anthropic or OpenAI after a per-provider consent sheet (guideline 5.1.2(i)). The server does not store questions, materials or answers.
- Plans: Free, Bandal Plus and Bandal Pro (auto-renewable, one group) and AI Credit (consumable), in Settings > 구독·사용량. Restore Purchases is on the plan screen.
- Sync is optional and uses the user's own iCloud or Google Drive. Lecture recording stays on the device. In-app browser (age rating 17+). Account deletion: Settings > 계정 > 계정 삭제.

External services
- Bandal server (auth.bandal.io / Supabase): account (ID, email, name, nickname); AI usage records; App Store transaction status; the invite code and which account invited which (account IDs only); the school directory.
- Anthropic, OpenAI: AI requests, only after consent. Anthropic also runs the school website search (school name and country only).
- Apple: Sign in with Apple, In-App Purchase. Google: Sign in with Google, Google Drive API for sync.
- No analytics, advertising or crash reporting. No device identifiers are collected.

Regional differences: not distributed in the EU or China mainland.
