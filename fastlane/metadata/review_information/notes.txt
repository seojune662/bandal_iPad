2. Purpose, audience, problem
Bandal (store name 반달 노트) is a study app for university students on iPad. Students keep lecture PDFs, handwritten notes and typed notes for each course in one place, instead of switching between separate PDF, note-taking and browser apps.

Version 1.0 works entirely on the device. There is no account creation or login, no syncing, no sharing of user content with other users, and no paid features or in-app purchases. All files are stored on the iPad.

3. How to use the main features (no login needed)
- Create a course: tap "+" next to the course list (과목) and choose "새 과목 만들기" (New Course), then enter a name.
- Import a PDF: put any PDF in the Files app (for example On My iPad > 반달), then in the app tap the tray icon "파일 가져오기" (Import Files) above the materials list (자료) and pick the PDF. Tap it in the list to open it.
- Handwriting: choose the pen, highlighter or eraser in the PDF toolbar and write with Apple Pencil. "+" > "새 노트" in the materials list creates a blank handwriting note (plain, lined, grid or dotted paper).
- Tabs and panes: "+" in the tab bar opens a new tab (handwriting note, Markdown, browser, AI). The layout button in the tab bar splits the workspace into two columns, two rows or four panes.
- Typed notes: "+" in the tab bar > "마크다운" creates a Markdown note.
- Browser: "+" in the tab bar > "브라우저", then enter an address.
- AI assistant (optional): this needs the user's own API key from OpenAI, Anthropic or Google, entered in Settings > AI 엔진 (AI Engine). Without a key the rest of the app works fully. We do not provide a key.
- No sample account is needed. Any PDF works as a sample file.

4. External services
- AI assistant (optional, user's own key): when the user asks a question, the question, any attached images and any material or note the user lets the AI read are sent from the iPad directly to the provider the user chose (OpenAI, Anthropic or Google), using the user's own API key stored in the iPad Keychain. Before the first request to each provider, the app shows a consent screen that says what is sent and to whom, with a link to the provider's privacy policy. Nothing is sent without consent, and consent can be withdrawn in Settings > AI 엔진. We run no server for this and never receive these requests or the key.
- In-app browser: loads the websites the user opens (and their icons) directly from those sites. The sidebar shortcuts to ChatGPT, Claude, Gemini and school websites only open those websites in this browser. Because the browser can open any website, the age rating is 17+.
- No analytics, advertising, crash-reporting, authentication or payment services are used. There is no server of ours that the app talks to.

5. Regional differences
The app is not distributed in the European Union. In all regions where it is available, the features are the same.

6. Regulated industry
Not applicable. The app is a general study and note-taking tool and is not in a regulated industry.
