# AI 공정 이용 안내

반달의 AI 기능은 따로 API 키를 넣지 않아도 바로 쓸 수 있어요. 반달이 AI 제공사(Anthropic, OpenAI)에 대신 요청하고 비용을 냅니다. 모두가 안정적으로 쓸 수 있도록 플랜마다 한 달 사용량과 한 번의 작업에 쓸 수 있는 양을 정해 두었어요.

## 월 사용량

AI를 쓸 때마다 실제로 든 비용만큼 이번 달 사용량이 줄어요. 앱의 **설정 › 구독·사용량**과 AI 모델 선택 창에서 몇 %를 썼는지 볼 수 있습니다.

| 플랜 | 한 달 사용량 | Auto 질문으로 치면 |
| --- | --- | --- |
| 무료 (로그인) | $0.02 | 약 25회 |
| Plus | $0.30 | 약 400회 |
| Pro | $1.20 | 약 1,700회 |
| 무료 체험 중 (Plus·Pro) | $0.30 | 약 400회 |

- 사용량은 **매달 1일 0시(한국 시간)**에 다시 채워져요. 남은 양은 다음 달로 넘어가지 않습니다.
- **Auto**는 빠르고 가장 적게 쓰는 모델이에요. 다른 모델을 고르면 같은 질문에도 더 많이 씁니다. 모델 목록의 **최대 N×** 표시는 Auto보다 최대 몇 배까지 쓸 수 있는지를 뜻해요.
- 긴 자료를 첨부하거나 Effort를 높이면(high, max) 한 번에 쓰는 양이 늘어요.
- Pro 무료 체험 기간에는 Plus와 같은 양을 쓸 수 있고, 유료로 전환되면 Pro 사용량(4배)이 적용돼요.

## 한 번의 작업 상한

AI가 자료를 여러 번 읽고 답을 이어 쓰는 긴 작업(요약, 퀴즈 만들기, 여러 단계로 진행되는 질문 등)은 한 번에 쓸 수 있는 양이 정해져 있어요. 한 작업이 월 사용량을 한꺼번에 다 쓰지 않게 하기 위해서예요.

| 플랜 | 작업 1회 상한 |
| --- | --- |
| 무료 | 월 사용량과 같음 ($0.02) |
| Plus · 무료 체험 | $0.10 |
| Pro | $0.50 |

상한에 닿으면 작업이 그 자리에서 멈추고 "이 작업이 상한에 닿아 멈췄어요"라고 알려 드려요. 그때까지 만든 결과는 남아 있습니다. Auto로 다시 하거나, 자료 범위를 나눠서 요청해 보세요.

## 사용량을 다 썼을 때

- **무료**: Plus 또는 Pro로 올리면 바로 이어서 쓸 수 있어요.
- **Plus**: Pro로 올리면 한 달 사용량이 4배가 돼요.
- **Pro**: 충전팩을 사면 이번 달 사용량을 다 쓴 뒤에 충전팩 잔액에서 이어서 씁니다. 충전팩 하나는 $2.00만큼이에요.
  - 충전팩 잔액은 매달 초기화되지 않고 남아 있어요.
  - 충전팩은 소모성 구매라 '구입 내역 복원'으로 되살릴 수 없어요.
  - 환불된 충전팩의 잔액은 회수돼요.

## 이럴 때는 사용량이 줄지 않아요

- AI 제공사가 요청을 받지 못했거나 오류로 거절했을 때
- 반달 서버나 AI 제공사의 일시적인 장애로 답을 시작하지 못했을 때

답이 나오는 도중에 앱을 닫거나 네트워크가 끊기면, 그때까지 AI가 실제로 만든 양만큼은 사용량에 포함돼요.

## 금지하는 이용과 제한

다음과 같은 이용은 허용하지 않아요.

- 한 사람이 여러 계정을 만들어 무료 사용량을 반복해서 받는 것
- 계정을 다른 사람과 나눠 쓰거나, 반달 AI를 다른 서비스·프로그램의 백엔드로 쓰는 것
- 앱을 거치지 않고 반달 서버에 직접 요청을 보내거나 자동화 도구로 대량 요청하는 것
- AI 제공사의 이용 정책([Anthropic](https://www.anthropic.com/legal/aup), [OpenAI](https://openai.com/policies/usage-policies))에 어긋나는 내용을 요청하는 것

이런 이용이 확인되면 사전 안내 없이 해당 계정의 AI 기능을 일시적으로 또는 영구적으로 제한할 수 있어요. 제한된 기간의 구독료는 App Store 환불 정책을 따릅니다. 제한이 잘못되었다고 생각되면 [hi@bandal.io](mailto:hi@bandal.io)로 알려 주세요.

## 데이터

AI에 보낸 질문과 자료는 답을 만들기 위해 선택한 AI 제공사로 전달되고, 반달 서버에는 내용이 저장되지 않아요. 반달은 사용량 계산을 위해 날짜, 모델, 토큰 수, 비용만 기록합니다. 처음 AI를 쓸 때 동의한 제공사별 데이터 전달 동의는 **설정 › AI**에서 확인하고 철회할 수 있어요.

## 바뀔 수 있어요

AI 제공사의 가격이나 모델이 바뀌면 사용량과 상한도 조정될 수 있어요. 조정할 때는 이 페이지를 먼저 고치고 앱 안에서 알려 드립니다.
